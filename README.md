## View the website with GitHub Pages

This repository deploys with **GitHub Actions** (see `.github/workflows/static.yml`).

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. Push to `main`, or run the workflow manually from the **Actions** tab.
4. After GitHub Pages publishes it, visit: https://arjungupta001.github.io/Portfolio-/

> Prefer the simpler setup? Delete `.github/workflows/static.yml` and instead choose **Deploy from a branch → `main` / `/(root)`**. Use one method or the other, not both.
